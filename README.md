# My First GitHub Page

A small personal site built with HTML, CSS, and JavaScript. It has no dependencies or build step, so GitHub Pages can serve it directly.

## Make it yours

1. Open `index.html` and replace `Your Name` and the sample introduction.
2. Update the learning list and project descriptions with your own progress.
3. Open `styles.css` to change the colors, spacing, and typography.
4. Open `script.js` to see a small JavaScript example that keeps the footer year current.

## Publish with GitHub Pages

1. Create a new GitHub repository and add these project files to it.
2. In the repository, open **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)` folder, then save.
4. GitHub will show the published page address in the Pages settings after deployment finishes.

The site is static: `index.html` is the entry page, and its CSS and JavaScript files live beside it. No compilation is needed.
